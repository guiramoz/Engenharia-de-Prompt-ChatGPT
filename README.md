# TaskFlow – Sistema de Gestão de Tarefas para Equipes Remotas

## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante o curso de **Inteligências Artificiais Generativas Aplicada ao ChatGPT** do SENAI. O objetivo é criar o **TaskFlow**, uma aplicação web de gestão de tarefas voltada para equipes de trabalho remoto, permitindo o gerenciamento de usuários, criação de tarefas, definição de prazos e acompanhamento da produtividade por meio de um dashboard.

Além do desenvolvimento da aplicação, o projeto teve como foco a utilização de técnicas de **Engenharia de Prompt**, aplicadas desde o levantamento dos requisitos até a construção da interface do sistema com o auxílio da Inteligência Artificial.

## 🤖 Engenharia de Prompt Aplicada

Durante o desenvolvimento foram utilizadas diferentes técnicas de Engenharia de Prompt:

* **Inversion Prompting** para o levantamento e refinamento dos requisitos do sistema, permitindo identificar funcionalidades, restrições e necessidades do projeto de forma estruturada.
* **Persona + Chain-of-Thought** para orientar a Inteligência Artificial durante a construção da aplicação, simulando um desenvolvedor especialista e organizando o processo de desenvolvimento de forma lógica, solocitando que ele utilizasse uma imagem da pasta imagens como referência para o design.

## 🚀 Funcionalidades

* Cadastro de usuários.
* Gerenciamento de equipes.
* Criação, edição e exclusão de tarefas.
* Atribuição de responsáveis às tarefas.
* Definição de prazos de entrega.
* Dashboard de produtividade.
* Visualização das tarefas de cada usuário.
* Interface responsiva e intuitiva.
* Validação e comportamento dos campos utilizando JavaScript.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* ChatGPT
* Engenharia de Prompt

## ⚙️ Funcionamento

1. Os requisitos da aplicação são elaborados utilizando a técnica **Inversion Prompting**.
2. O desenvolvimento da interface é conduzido com o auxílio das técnicas **Persona** e **Chain-of-Thought**.
3. A interface é construída utilizando **HTML** e **CSS**.
4. O **JavaScript** é responsável pela interação da aplicação, validação dos campos e comportamento dos elementos da interface.
5. O projeto é executado localmente em um navegador para fins de demonstração e testes.
6. Caso sejam utilizadas bibliotecas ou dependências adicionais, elas devem ser instaladas antes da execução do projeto.

## 💻 Ambiente de Execução

Este projeto foi desenvolvido para ser executado **localmente**, não possuindo integração com backend ou banco de dados. Toda a interface e as interações são realizadas no lado do cliente (client-side), utilizando apenas HTML, CSS e JavaScript.

## 🎯 Objetivo

Este projeto possui finalidade acadêmica e tem como objetivo demonstrar a aplicação de técnicas de **Engenharia de Prompt** no processo de desenvolvimento de software, utilizando o ChatGPT como ferramenta de apoio na definição dos requisitos e na construção da interface. Além disso, busca integrar conceitos de desenvolvimento web com Inteligência Artificial Generativa, evidenciando como técnicas como **Inversion Prompting**, **Persona** e **Chain-of-Thought** podem tornar o desenvolvimento mais organizado e eficiente.
